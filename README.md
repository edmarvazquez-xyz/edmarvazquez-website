# edmarvazquez.xyz

Personal website and digital home of Edmar Vazquez.

## Philosophy

This website is intentionally simple.

It is built using:

- HTML
- CSS
- Git
- GitHub

No frameworks.
No JavaScript (for now).
No tracking.
No unnecessary complexity.

## Goals

- Personal homepage
- Portfolio
- Notes and writing
- Projects
- Contact information

## Development

Clone:

```bash
git clone git@github-personal:edmarvazquez-xyz/edmarvazquez-website.git
```

Run locally:

```bash
xdg-open index.html
```

## Deployment

Hosted using GitHub Pages and/or Cloudflare Pages.
